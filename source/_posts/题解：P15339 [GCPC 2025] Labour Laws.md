# 题解：P15339 [GCPC 2025] Labour Laws

## 思路

我们需要根据给定的总时间 $t$（单位：分钟），计算出符合德国《工作时间法》的最少休息时间 $r$。法律规定：

- 工作时间 $w$ 不能超过 $600$ 分钟（$10$ 小时）。
- 如果 $w > 360$，则必须休息至少 $30$ 分钟。
- 如果 $w > 540$，则必须休息至少 $45$ 分钟。

总时间 $t = w + r$，且 $r \ge 0$。目标是让 $r$ 尽可能小，即让 $w$ 尽可能大，同时满足上述约束。

我们可以将问题转化为：寻找最大的可行工作时间 $w$，然后 $r = t - w$。约束条件可写为：

- $w \le 600$
- 如果 $w > 360$，则 $t - w \ge 30$，即 $w \le t - 30$
- 如果 $w > 540$，则 $t - w \ge 45$，即 $w \le t - 45$

同时 $w \le t$ 自然成立。由于 $w$ 要最大化，我们考虑不同取值区间，但可以通过几个关键候选值来得到最小 $r$。我们可以直接推导出最少休息时间的表达式。考虑以下四种情况：

1. 基础时间：工作时间不能超过 $600$，所以 $w \le 600$，即 $r = t - w \ge t - 600$。因此休息时间至少为 $\max(0, t-600)$（因为 $r$ 非负）。
2. 超过 $6$ 小时：如果让工作时间恰好为 $360$，则休息时间为 $t-360$；如果让工作时间恰好为 $t-30$（即休息 $30$ 分钟），则工作时间为 $t-30$。这两种方式都能满足“超过 $6$ 小时需休息 $30$ 分钟”的条件（注意当 $w=360$ 时正好等于 $6$ 小时，不需要休息，但此时休息时间 $t-360$ 可能小于 $30$）。取两者中较小的休息时间，即 $\min(30, t-360)$，这是仅考虑该规则时的可能最小休息。
3. 超过 $9$ 小时：类似地，让工作时间恰好为 $540$ 需休息 $t-540$，让工作时间恰好为 $t-45$ 需休息 $45$ 分钟。取较小者 $\min(45, t-540)$。
4. 最终答案：实际需要的休息时间必须同时满足上述所有条件，因此它至少是这些下限中的最大值。同时，由于这些候选值本身都是可行的（在相应条件下），取最大值就得到了满足所有条件的最小休息时间。

因此答案为：

$$
r = \max\left(0,\; t-600,\; \min(30, t-360),\; \min(45, t-540)\right)
$$

## 代码

```cpp
#include <bits/stdc++.h>
#define endl '\n'
using namespace std;
int t;
int main()
{
    cin >> t;
    cout << max({0, t - 600, min(30, t - 360), min(45, t - 540)}) << endl;
    return 0;
}
```
