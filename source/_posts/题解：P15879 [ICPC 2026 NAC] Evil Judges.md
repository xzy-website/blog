# 题解：P15879 \[ICPC 2026 NAC] Evil Judges

## 思路

题目要计数的子序列是 `AC` 和 `AK`，不要求连续。对于字符串中的每一个 `C` 或 `K`，它能和它前面的每一个 `A` 组成一个满足条件的子序列。

因此，如果遍历字符串时维护一个计数器 $\text{cnt}$ 表示当前遇到的 `A` 的个数，那么每碰到一个 `C` 或 `K`，就会新增 $\text{cnt}$ 个子序列。初始的总子序列数记为 $\text{sum}$。

接下来思考，一次相邻交换能改变什么？

考虑交换相邻的两个字符 $s_i$ 和 $s_{i + 1}$：

- `A` 与 `C` 或 `K` 相邻（`A` 在左）：交换前这对字符本身构成一个 `AC` 或 `AK`，交换后 `A` 跑到右边，该子序列消失。同时，其他字符与该对的配对变化恰好抵消，所以总数减少 $1$。
- `C` 或 `K` 与 `A` 相邻（`C` 或 `K` 在左）：交换前不构成子序列，交换后新增一个，总数增加 $1$。
- 两个相同字符或 `C` 与 `K`：交换不会改变任何 `A` 与 `C` 或 `K` 的相对顺序，总数不变。

由此得出结论：一次操作最多让子序列总数减少 $1$。

那么如何达到每次减 $1$ 的效果？考虑贪心策略：只要当前字符串中还存在至少一个 `A` 后面跟着 `C` 或 `K`，就找到最左边的这样的 `A`，让它和右边紧邻的 `C` 或 `K` 交换。

这样一次交换必然使总数减 $1$，并且不会在其他位置产生新的子序列。

如果不断地执行这种操作，每步都扣除一个子序列，直到以下两种条件中的一条达成：

- 操作次数 `M` 用完
- 所有 `A` 都移动到了所有 `C` 或 `K` 的右边（此时总数为 $0$）。

因此，在最优操作下，我们能消灭 $\min(\text{sum}, \text{M})$ 个子序列，剩余的最少数量为 $\max(\text{sum} - \text{M}, 0)$。

## 证明

:::info[每次相邻交换对子序列总数的改变量]
设交换相邻字符 $X = s_i$ 和 $Y = s_{i + 1}$。

定义字符串中所有相对顺序满足 `A` 在 `C` 或 `K` 之前的无序对 $(\text{posA}, \text{posCK})$ 为一个子序列。

交换只会影响那些至少有一个端点位于位置 $i$ 或 $i + 1$ 的对。具体地：

- 若 $X = \text{A}$，$Y = \text{C 或 K}$：
  交换前 $(i, i+1)$ 有效；交换后该对顺序颠倒，失效。
  对于其他位置 $p$（$p < i$ 或 $p > i+1$）与这两个位置的配对，可以验证增加与减少的数量互相抵消。最终变化为 $-1$。
- 若 $X = \text{C 或 K}$，$Y = \text{A}$：
  类似推理可得变化为 $+1$。
- 其他情况（$X = Y$ 或 $X,Y \in \text{C, K}$）：
  不会改变任何 `A` 与 `C` 或 `K` 的相对顺序，变化为 $0$。

因此，任意一次相邻交换对总数的改变量属于 ${-1, 0, 1}$，且能造成 $-1$ 的条件是交换了一个 `A`（左）和一个 `C` 或 `K`（右）。

这就证明了每次操作最多减少 $1$。
:::

:::info[下界的可达性]
我们假设，对于任意字符串，如果 $sum > 0$，则必然存在一对相邻的 `A`（左）和 `C` 或 `K`（右）。

证明：若不存在这样的相邻对，则每个 `A` 的右边要么是另一个 `A`，要么没有字符，要么是 `C` 或 `K` 但在左边。这意味着所有 `A` 都在所有 `C` 或 `K` 的右边，而此时 $sum = 0$，矛盾。

因此，只要 $sum > 0$，就可以执行一次使总数减 $1$ 的交换。重复这个操作，每一步都减少 $1$，直到 $sum = 0$ 或操作次数耗尽。

所以最终最少剩余数量为 $\max(\text{sum - M}, 0)$。

这个值既是理论上界，也是可达的，故为最优解。
:::

## 代码

```cpp
#include <bits/stdc++.h>
#define endl '\n'
using namespace std;

string s;
long long M, cnt, sum;

int main(){
    cin >> s >> M;
    for(int i = 0;i < s.size();i++){
        if(s[i] == 'A')
            cnt++;
        else
            sum += cnt;
    }
    cout << max(sum - M, 0LL) << endl;
    return 0;
}
```
