# 题解：P16779 ⌈Xzy OI R1 T1⌋ 查查编

这里是出题人题解。

## 思路

::::info[子任务 $1$]
我们考虑去枚举或二分 $b$ 的值。

根据完全二叉搜索树的性质，如果确定了节点总数 $n = b - a + 1$，那么根节点在整棵树中的相对排名（即左子树的节点数 $+ 1$）是唯一确定的。

那么我们先需要找出除最后一层外，整棵满二叉树的高度 $h = \lfloor\log_2(n + 1)\rfloor$。然后可以很容易地推算出前 $h-1$ 层满二叉树的节点总数为 $2^{h-1} - 1$。用总节点数减去前 $h$ 层的满节点数，就能得到最后一层的剩余节点数为 $n - (2^h - 1)$。

由于在完全二叉树中，这些剩余节点会优先填满左子树，而左子树在最后一层最多只能容纳 $2^{h-1}$ 个节点，因此我们就可以准确地计算出左子树最终所分配到的节点总量。

如果当前枚举的 $b$ 满足 $x - a$ 与左子树节点数相等，则说明该 $b$ 合法。由于根节点的左子树大小随 $n$ 的增加具有单调性，我们可以直接在 $[x, 2 \times x]$ 范围内二分 $b$ 的值。
::::

::::info[子任务 $2$]
我们注意到，这里有一个非常特殊的条件：$x - a = 2^k - 1$。

可以发现，$x - a$ 正好是根节点左子树的节点数量。而 $2^k - 1$ 恰好是一棵完美的满二叉树的节点总数。

那么开始思考，如果左子树是一棵高度为 $k$ 的满二叉树，为了让整棵树保持“完全二叉树”的性质（即最后一层从左往右紧密排列），右子树的形态只有两种可能：

1. 右子树也是一棵高度为 $k$ 的满二叉树（此时整棵树是一棵完全满的二叉树）。
2. 右子树是一棵高度为 $k-1$ 的满二叉树（最后一层还没蔓延到右子树）。

因为题目要求 $b$ 的最大值，我们一定会倾向于让右子树“尽可能填满”。如果右子树也是高度为 $k$ 的满二叉树，右子树节点数同样为 $2^k - 1$。此时总节点数达到该形态的最大值，即右子树的最大编号 $b = x + (2^k - 1) = 2 \times x - a$。
::::

结合前面的思考，我们跳出二分，直接来观察左子树节点数 $L = x - a$ 与右子树最大节点数 $R_{max}$ 的关系。

令 $t = \lfloor \log_2 L \rfloor$，即 $L$ 的最高二进制位。我们可以将 $L$ 的状态分为两种情况讨论：

1. 情况 $1$：$L = 2^{t+1} - 1$（子任务 $2$）

   此时左子树是一棵完美的满二叉树。为了让 $b$ 最大，右子树也可以被完全填满成一棵与左子树一模一样的满二叉树。

   - 右子树最大节点数 $R_{max} = L = 2^{t+1} - 1$。
   - 最大编号 $b = x + R_{max} = x + (x - a) = 2 \times x - a$。
2. 情况 $2$：$2^t \le L < 2^{t+1} - 1$

   此时左子树的最后一层已经有节点，但还没有填满。根据完全二叉树的定义，最后一层的节点必须从左往右连续排列。既然左子树都还没填满，说明最后一层的指针根本还没有指到右子树去。因此，右子树的最后一层只能是空的。进而，右子树最多只能是一棵高度为 $t$ 的满二叉树。

   - 右子树的最大节点数 $R_{max} = 2^t - 1$。
   - 最大编号 $b = x + R_{max} = x + 2^t - 1$。

最后，我们可以利用内置位运算函数 `__builtin_clzll`（计算前导零的个数）来求出一个数的最高位。

## 代码

```cpp
#include <bits/stdc++.h>
#define endl '\n'
using namespace std;
long long T, a, b, x, L, t, p;
void mian()
{
    cin >> a >> x;
    L = x - a;
    // 特判，如果左子树为空那么右子树也为空。
    if (L == 0)
    {
        cout << x << endl;
        return;
    }
    t = 63 - __builtin_clzll(L); // t = floor(log2(L))，即 L 的最高位
    p = 1LL << t;
    // 情况 1
    if (L == (1LL << (t + 1)) - 1)
        b = 2 * x - a;
    // 情况 2
    else
        b = x + p - 1;
    cout << b << endl;
}
int main()
{
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);
    cin >> T;
    while (T--)
        mian();
    return 0;
}
```
