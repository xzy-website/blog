# 题解：P17281 「IXOI R2」阴圆

## 思路

题目要求我们找出所有可能的最大公约数，这些公约数必须由至少两个不同的整数（从 $1$ 到 $n$ 中选取）得到，且每次选取后可重复。

设最终得到的最大公约数为 $d$。那么所有被选中的数都必须是 $d$ 的倍数。

因为我们至少要选两个不同的数，所以这两个不同数中最小的一对就是 $d$ 和 $2d$。

因此，必须有 $2d \le n$，即 $d \le \lfloor \frac{n}{2} \rfloor$。

反过来，对于任意满足 $d \le \lfloor n/2 \rfloor$ 的正整数 $d$，我们只需要选取两个数 $d$ 和 $2d$，它们的最大公约数恰好是：$\gcd(d, 2d) = d$。

由于 $2d \le n$，这两个数都在合法范围内，因此这样的 $d$ 一定可以获得。

所以所有可获得的 $d$ 正好是集合：

$$
\{1, 2, 3, \dots, \lfloor n/2 \rfloor\}
$$

它们的个数就是 $\lfloor n/2 \rfloor$。

## 代码

```cpp
#include <bits/stdc++.h>
#define endl '\n'
using namespace std;
long long n;
int main()
{
    cin >> n;
    cout << n / 2 << endl;
    return 0;
}
```
