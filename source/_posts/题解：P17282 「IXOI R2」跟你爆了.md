# 题解：P17282 「IXOI R2」跟你爆了

场上差点就跟这题爆了。

## 思路

给定一个长度为 $n$ 的非负整数序列 $a_1,a_2,\dots,a_n$，定义区间 $[l,r]$ 的“信息密度”为

$$
\frac{\sum_{i=l}^r a_i}{r-l+1}
$$

要求找出所有密度非零的区间中密度最小的一个，并以最简分数 $\frac{x}{y}$ 输出。

由于所有 $a_i \ge 0$，任何密度非零的区间内至少包含一个正数。

考虑任意一个最优区间 $I$。若 $I$ 中含有多个正数，我们可以将这些正数连同它们之间的 $0$ 分割成若干段，每段恰好包含一个正数，且段内不跨越其他正数。设这些段的长度分别为 $L_1,L_2,\dots,L_k$，段内正数值分别为 $b_1,b_2,\dots,b_k$，则整个区间的密度为：

$$
\frac{\sum b_j}{\sum L_j}
$$

这是一个加权平均值（权重为 $L_j$），因此它一定不小于这些段中密度最小的那个，即存在某一段 $j$ 满足：

$$
\frac{b_j}{L_j} \le \frac{\sum b_j}{\sum L_j}
$$

而每一段只含一个正数，如果我们将该正数向左右扩展到整个序列中连续 $0$ 的边界（即不包含其他正数），其长度只会增大（分子不变），所以该正数单独扩张的密度不会大于 $\frac{b_j}{L_j}$。于是 $\frac{b_j}{L_j}$ 要在单个正数扩张的密度和原区间密度之间。

因此，最优区间一定可以取为某个正数加上它左右连续的所有 $0$。

所以我们只需要枚举每个正数 $a_i$，考虑区间 $i$ 减左边连续 $0$ 个数到 $i$ 加右边连续 $0$ 个数，其密度为：$a_i$ 除以左边 $0$ 个数加右边 $0$ 个数加 $1$。

取其中的最小值即可。

## 代码

```cpp
#include <bits/stdc++.h>
#define endl '\n'
using namespace std;

long long n, l, x, y, a[1000005], r[1000005];

long long cal(long long x, long long y)
{
    long long t;
    while (y)
    {
        t = x % y;
        x = y;
        y = t;
    }
    return x;
}

int main()
{
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);
    cin >> n;
    for (long long i = 1; i <= n; i++)
        cin >> a[i];
    for (long long i = n; i >= 1; i--)
    {
        if (a[i] == 0)
            r[i] = r[i + 1] + 1;
        else
            r[i] = 0;
    }
    x = 1000000001, y = 1;
    for (long long i = 1; i <= n; i++)
    {
        if (a[i] == 0)
            l++;
        else
        {
            if (a[i] * y < x * (l + r[i + 1] + 1))
            {
                x = a[i];
                y = l + r[i + 1] + 1;
            }
            l = 0;
        }
    }
    cout << x / cal(x, y) << " " << y / cal(x, y) << endl;
    return 0;
}
```
