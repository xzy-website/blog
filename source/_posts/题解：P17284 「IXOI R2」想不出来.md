# 题解：P17284 「IXOI R2」想不出来

## 思路

不去考虑模拟，考虑哪些最终的序列能够出现。然后就是一个 $O(n^2)$ 的 DP！

我们设最终序列为 $p$。

可以证明，$p$ 可达当且仅当满足下面两条：

1. 如果 $p_i>0,p_{i+1}>0$，那么一定有 $p_i=p_{i+1}=1$；
2. 如果 $p_i=p_{i+1}=1$，那么实际上左边所有质量都没有越过这两个位置，因此必须满足 $\sum_{j=1}^{i-1}p_j=i-1$。

直观上，两个相邻的 $1$ 如果最终同时存在，那么这两个位置不可能经历过合并操作，否则想把它们重新恢复成两个相邻的正数是不可能的。因此它们两边完全独立。

特别地，如果一个合法序列中不存在相邻的正数，那么它一定可以构造出来。

所以问题就变成枚举所有满足上述性质，且 $\sum p_i=n$ 的序列，求 $\prod x_i^{p_i}$ 的总和。

::::info[证明]
设最终序列为 $p$。

一次操作只会把 $i-1,i,i+1$ 三处的总和集中到 $i$，因此总和始终为 $n$。

若最终 $p_i,p_{i+1}>0$，则 $i,i+1$ 之后都不能再作为操作中心，否则会使相邻位置变为 $0$。因此这两个位置从始至终都没有发生质量合并，只能保持初始值 $1$，故必有 $p_i=p_{i+1}=1$。

进一步，若 $p_i=p_{i+1}=1$，则这两个位置形成一道墙，任何操作都不能使质量跨过它们，否则至少有一个位置会发生变化。因此左侧位置始终只包含最初的 $i-1$ 个单位质量，故 $\sum_{j=1}^{i-1}p_j=i-1$。

反过来，满足这三个条件的序列，可以把所有 $p_i>1$ 的位置不断逆着操作拆分，最终还原为全为 $1$ 的；相邻的 $1,1$ 由前缀条件隔开，左右部分可独立还原。
::::

那么来考虑 DP 的设计。

定义 $f_{x, y}$（$0 \le x \le 2$）为处理到当前位置，前缀和为 $y$，当前 $p_i=x$（若 $x$ 为 $2$ 则 $p_i \ge 2$），转移到第 $i$ 位，同时定义 $g$ 为当前的 DP 数组，$f$ 为上一轮的 DP 数组。

对于转移：

- $p_i = 0$：

  什么限制都没有。

  $$
  g_{0,s}=f_{0,s}+f_{1,s}+f_{2,s}
  $$
- $p_i = 1$：

  如果前一个是 $0$，一定可以直接转移。

  如果前一个也是 $1$，根据性质，必须有处理完前 $i-1$ 个数时前缀和正好为 $i-1$。由于当前 $p_i=1$，所以处理完第 $i$ 个数后前缀和必须为 $s=i$。

  因此：

  $$
  g_{1,s}=
  \begin{cases}
  x_i \times (f_{0,s-1}+f_{1,s-1}), &s=i\\
  x_i \times f_{0,s-1}, &s \not= i
  \end{cases}
  $$
- $p_i \ge 2$：

  这时前一个一定只能是 $0$。

  因此：

  $$
  g_{2,s}=\sum_{k=2}^{s}f_{0,s-k} \times x_i^k
  $$

  直接枚举 $k$ 会变成 $O(n^3)$，但这个式子是等比形式，可以递推：

  $$
  g_{2,s} = x_i \times g_{2,s-1} + x_i^2 \times f_{0,s-2}
  $$

  于是每一层只需要 $O(n)$。

## 代码

```cpp
#include <bits/stdc++.h>
#define endl '\n'
#define MOD 1000000007
using namespace std;

long long n, x[8005];
long long f[3][8005], g[3][8005];

int main()
{
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);
    cin >> n;
    for (long long i = 1; i <= n; i++)
        cin >> x[i];
    f[0][0] = 1;
    for (long long i = 1; i <= n; i++)
    {
        for (long long j = 0; j <= n; j++)
            g[0][j] = g[1][j] = g[2][j] = 0;
        for (long long s = 0; s <= n; s++)
            g[0][s] = (f[0][s] + f[1][s] + f[2][s]) % MOD;
        for (long long s = 1; s <= n; s++)
        {
            if (s == i)
                g[1][s] = ((f[0][s - 1] + f[1][s - 1]) % MOD) * x[i] % MOD;
            else
                g[1][s] = f[0][s - 1] * x[i] % MOD;
        }
        for (long long s = 2; s <= n; s++)
            g[2][s] = (x[i] * g[2][s - 1] + (x[i] * x[i] % MOD) * f[0][s - 2]) % MOD;
        for (long long s = 0; s <= n; s++)
        {
            f[0][s] = g[0][s];
            f[1][s] = g[1][s];
            f[2][s] = g[2][s];
        }
    }
    cout << (f[0][n] + f[1][n] + f[2][n]) % MOD << endl;
    return 0;
}
```
